# Newcastle United 2025/26 Interactive Analytics Dashboard

Interactive Streamlit portfolio dashboard for the Newcastle post-goal control study.

## Run on your Mac
1. Open Terminal in this folder.
2. Run: `python3 -m pip install -r requirements.txt`
3. Run: `python3 -m streamlit run app.py`
4. Your browser will open the dashboard locally.

## Put it online
Upload this folder to a GitHub repository, then deploy `app.py` with Streamlit Community Cloud. Keep the `data/` folder in the repository because the app reads those files.

## Dashboard sections
- Overview
- 5/10/15-minute post-goal analysis
- Interactive shot map
- Territorial-pressure mechanism
- Players & units
- Match explorer
- Methodology

## Important interpretation
This is an observational one-season study. Player/unit and pressure findings are associations, not causal estimates.
